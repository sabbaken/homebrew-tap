# homebrew-tap

Homebrew formulae for [@sabbaken](https://github.com/sabbaken).

## reminders-ha-sync

Two-way sync between macOS Reminders and Home Assistant to-do lists.

```sh
brew install sabbaken/tap/reminders-ha-sync
reminders-ha-sync setup
```

Source and documentation:
[apple-reminders-sync-to-home-assistant](https://github.com/sabbaken/apple-reminders-sync-to-home-assistant).
